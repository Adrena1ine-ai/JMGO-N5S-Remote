# JMGO N5S Ultra Max — подписанные обновления панели

Публичный отдельный канал для KD11CN; неофициальная модификация, не поддерживается JMGO. Исходный код адаптации, OEM прошивки, приватные ключи и домашние IP остаются только в локальном проекте server57.

Целевое устройство: ro.product.model=KD11CN, package com.jmgo.setting.clone. Android-приложение самостоятельно проверяет файл n5s-update.json из GitHub Releases. Перед установкой проверяет целевую модель/канал, версию, размер, SHA256 и сертификат установленного приложения; установка выполняется только системным Android PackageInstaller с подтверждением пользователя.

Сборки для N3 — в отдельном репозитории https://github.com/Adrena1ine-ai/JMGO-N3-Remote. Смешивать APK разных моделей без аппаратной проверки нельзя.

Статус: канал создаётся для реального теста обновления с установленной V95.8/code3681 на N5S. Первый релиз будет опубликован только после проверки APK и цели.
